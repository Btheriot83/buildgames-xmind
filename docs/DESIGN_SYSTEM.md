# Shop Chalk Map — design system (elevate)

Derived from locked IDENTITY + live board screenshots. Every elevate artifact starts here.

## Fonts
- Display / root: **Bricolage Grotesque** (root pill, brand, outline root)
- Body / UI / limbs: **IBM Plex Mono**
- Never: Inter, Geist, Space Grotesk, Fraunces-everywhere

## Colors (flat — no decorative gradients)

## Spacing
- Toolbar min-height ~52px
- Sidebar ≤148px (map owns frame)
- Outline tree: 28–36px page pad, 18px indent steps
- Node gap / fan: ~64–72px vertical

## Components
- **View switch**: Map | Outline (MindNode dual)
- **Root pill**: amber chalk oval
- **Limb cards**: dark fill + chalk outline (Heptabase card air, chalk materials)
- **Job cluster**: Branch / Sibling / Link / Export — Export sole hot tablet
- **More**: AI Expand, Grow from outline, Delete, Blank, Import

## Do
- Flat fills + real chalkboard photo underlay
- Organic bezier limbs
- Dual map/outline
- Shop-short copy

## Don’t
- Copper Synapse branding
- Vibe-purple / glass / soft gradient chrome
- Soft drop shadows as decoration
- Inter / Geist defaults
