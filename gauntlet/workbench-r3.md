## Phase B3 — 20 rounds under Shop Chalk Map

### R1 — Type hierarchy
- **Piece:** Root/display vs limb mono sizes muddy; map title mono-small.
- **Builder:** Root 17px/700 Bricolage; limbs 14px/500 Plex Mono; map title display 1.05rem/600; brand display clamp tightened.
- **Critic (pixels):** Central topic pops; limbs secondary. Gap: sidebar Maps title still soft.
- **Verdict:** hierarchy up · **6.9**

### R2 — Contrast hold
- **Piece:** `--bone-dim #b9b49a` on ink-2 ~5.4:1; job-tape even spans washed.
- **Builder:** chalk-dim → `#c9c4a8`; line → `#4a6b58`; job tape all ink `#14241c` on copper; muted labels use chalk-dim.
- **Critic:** Small chrome labels hold. Gap: brand tagline should stay copper-hot (kept).
- **Verdict:** contrast pass · **7.0**

### R3 — Button system (flat chalk blocks)
- **Piece:** Default `.btn` still pill `999px` while job was square — AI tell mash.
- **Builder:** All buttons → 4px radius, 2px borders, min-height 36, mono 0.8rem/500. Hard offset shadow only on primary.
- **Critic:** Reads as one control family. Gap: weight still unclear until R4.
- **Verdict:** craft unify · **7.1**

### R4 — Primary vs secondary weight
- **Piece:** Export SVG and AI Expand both copper — two primaries (Xmind uses one dark primary + outline secondary).
- **Builder:** Export = sole `job-primary` copper; AI Expand → `secondary` chalk outline; Outline → ghost; Delete → danger outline.
- **Critic:** Blind vs Xmind CTA pattern — closer. Export earns weight.
- **Verdict:** button weight win · **7.25**

### R5 — Off-palette hover kill
- **Piece:** `.btn:hover` used slate `#1e2630`; active map `#241c14` brown wash.
- **Builder:** Hover/active → board greens `#2c4538` / `#2a3f34`.
- **Critic:** No slate/brown fight on green board.
- **Verdict:** palette coherence · **7.3**

### R6 — Boot / toast / success chrome
- **Piece:** Skeleton/success still SaaS slate `rgba(18,20,26)`.
- **Builder:** Board-green overlays `#24382e` / `rgba(30,51,40,…)`.
- **Critic:** Boot no longer flashes foreign dark UI.
- **Verdict:** chrome match · **7.35**

### R7 — Solid chalk limbs (Xmind map craft)
- **Piece:** Always-dashed edges read unfinished vs Xmind solid curves.
- **Builder:** Default solid teal bezier; dash + pulse only in link mode / `is-linking`.

- **Verdict:** biggest map-craft delta · **7.5**

### R8 — Node silhouette
